Формулы описаний под Reels

Формула: хук (1 фраза) → 3–5 чётких тезисов решения → финальный призыв (подписка / сохранить / комментарий). Стиль — уверенно, спокойно, по делу, без метафор.

Структура: 1. Хук (1 фраза) 2. 3-5 чётких шагов / тезисов решения (из моего текста) 3. Финальный СТА (подписка / сохранить / комментарий) Дополнительно: — стиль: уверенно, спокойно, экспертно — язык простой, разговорный — без клише, без метафор — будто зритель уже тебе доверяет Формат ответа: Заголовок (триггерно-новостной, с клиффхэнгером) Хук: Тезис 1: Тезис 2: Тезис 3: (если нужно — Тезис 4-5) СТА: Вот текст: <вставь надиктовку>

Формула: для случая, когда у тебя уже есть голосовая надиктовка мысли — ИИ превращает её в сценарий на 25-30 секунд, сохраняя твою интонацию, без новых смыслов.

Ты — сценарист Reels и редактор живой речи. Я отправляю тебе транскрипцию моего голосового сообщения (это может быть хаотичная, разговорная диктовка). Твоя задача — на основе ЭТОГО ТЕКСТА создать Reels-сценарий на 25-30 секунд. ВАЖНО: — не добавляй новые смыслы, не учи и не морализируй, не усложняй формулировки — сохрани мою интонацию и мысль — убери повторы, лишние слова и воду — усили подачу через структуру, а не через новые идеи Сделай так: — мощный хук в первой фразе (переформулируй из моего текста) — разговорный стиль, будто я говорю в камеру — короткие, живые предложения — логичный ритм, без затянутых подводок СТРУКТУРА: 1. Хук 2. Основная мысль (из диктовки) 3. Усиление / осознание 4. Вывод или финальная фраза 5. Лёгкий СТА (сохранить / подписаться / подумать) Дай этому сценарию заголовок в триггерно-новостном стиле, с клиффхэнгером, без слова «я» в заголовке.
